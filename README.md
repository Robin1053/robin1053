### 🔧 Embedded & Automatisierung

Das ist mein Handwerk aus der Ausbildung — nicht nur gelesen, sondern gebaut und in Betrieb genommen:

| Bereich | Konkret |
|---|---|
| **Steuerungstechnik** | SPS-Programmierung, Schrittketten, Störungs-/Fehlerbausteine, HMI-Anbindung |
| **Sensorik & Signale** | Grenzwertauslegung, Entprellung, digitale Ein-/Ausgänge, Parametrierung von Feldgeräten |
| **Leistungselektronik** | H-Brücke, PWM, Tiefsetzsteller, Gleichrichter, Frequenzumrichter |
| **Antriebstechnik** | Servoantriebe, Asynchronmaschine, Regelungstechnik |
| **Aufbau & Abnahme** | Schaltschrankverdrahtung, Bussysteme, Pneumatik, Prüfung nach VDE 0100-600 |
| **Mikrocontroller** | C/C++ auf AVR (ATmega328) mit PlatformIO, I²C-Peripherie, Tasterentprellung |

**Abschlussprojekt (85/100 Punkte):** Vakuumüberwachung an einer Produktionsanlage. Vakuum-Ejektoren mit Druckschwellen ausgelegt (Haltekraft über die Saugerfläche gerechnet), Überwachungslogik in der SPS mit Druckaufbau-Fenster, Warn- und Fehlerbereich, Entprellung und automatischem Wiederholversuch, Meldung ans HMI, Abnahme und Inbetriebnahmeprotokoll nach VDE.

### 🚀 Projekte

- **[visca-bridge](https://github.com/Robin1053/visca-bridge)** — Bridge zwischen **VISCA-over-IP und RS-232** für Kamerasteuerung. Python-Backend mit TCP- (Port 52381) und UDP-Server (Port 1259), Auto-Reconnect auf der seriellen Schnittstelle, Preset-Verwaltung und REST-API; Weboberfläche mit Vite + React + TypeScript. *Mein bisher hardwarenächstes Software-Projekt.*

- **AVR-Playground (PlatformIO)** — C++ auf einem ATmega328: I²C-LCD, 5-Wege-Taster mit automatischer Ruhepegel-Erkennung und Entprellung. Übungsboden für alles, was danach kommt.

- **[@robineb/mui-utility](https://github.com/Robin1053/Mui-Utility)** — veröffentlichtes npm-Paket mit wiederverwendbaren MUI-Komponenten (`ActionButton`, `NotificationProvider`).

- **[Portfolio-Homepage](https://github.com/Robin1053/Portfolio-Homepage)** — meine Website mit Next.js und TypeScript, deployt über eine eigene CI/CD-Pipeline.
